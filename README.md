**Mad4kickz** es una plataforma web interactiva y responsiva dedicada a la exhibición y catálogo de calzado deportivo (*On Running*) para hombres y mujeres. El sitio ofrece una experiencia de usuario fluida con filtrado dinámico por precios y categorías.

👉 **Sitio en vivo:** [https://jwkeith.github.io/mad4kickz/](https://jwkeith.github.io/mad4kickz/)

## ✨ Características Principales

- 👨‍🦱👩 **Navegación por Categorías:** Secciones especializadas para los catálogos de **Hombre**, **Mujer** y **Ofertas**.
- 🔍 **Filtros e Interacción Dinámica:** Búsqueda e interacción en tiempo real mediante JavaScript para filtrar productos por precio y tipo de calzado.
- 📱 **Diseño Totalmente Responsivo:** Adaptado a pantallas móviles, tablets y ordenadores de escritorio.
- 💬 **Atención Directa:** Canales de contacto directo para agilizar la interacción con el cliente.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica de las páginas.
- **CSS3:** Estilos personalizados, diseño adaptativo (*responsive*) y animaciones.
- **JavaScript (ES6+):** Lógica interactiva para la manipulación del DOM y filtrado de productos.
- **GitHub Pages:** Despliegue y alojamiento continuo del proyecto.
